# קרדיט תמונות

כל התמונות באפליקציה ברישיון חופשי לשימוש מסחרי, ממקור Wikimedia Commons. הרשימה המלאה (קובץ, יוצר, רישיון, קישור) נמצאת ב-`assets/credits.json` ומוצגת גם באפליקציה: פרופיל ← עזרה ודיווח ← קרדיט תמונות.

- איורי תרגילים: Everkinetic – CC BY-SA 3.0 (גרסאות "light" הן עיבוד צבע של אותם איורים, באותו רישיון).
- תמונות מזון: CC0 / Public domain / CC BY / CC BY-SA לפי הקובץ.
- לא נעשה שימוש בתמונות אריזה של מותגים (GO, PRO וכו׳) – מוצגת אייקונה עד שתתווסף תמונה מורשית או תמונת Open Food Facts.
- תמונות אנשים (דוגמן, פנים באתגר): לא נמצאו במקורות חופשיים באיכות מתאימה; מוצגים איור ואותיות שם. ניתן להוסיף תמונות מורשות לתיקייה `assets/photos/`.
